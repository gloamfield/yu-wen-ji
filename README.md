# 余温机

一部会自己继续生活的 AI 小手机。免费、开源、本地优先，最终交付是一个可以直接双击打开的单文件 HTML。

> 当前版本：`0.6.0`  
> 在线体验：<https://gloamfield.github.io/yu-wen-ji/>  
> 许可证：MIT  
> 没有账号、没有作者服务器、没有付费门禁、没有激活码。

## 这是什么

余温机把 AI 角色放进一台虚构手机里。你可以解锁屏幕、看通知、和角色单聊或群聊、刷角色动态、打电话、写日记、记纪念日、整理相册、听歌、逛论坛，也可以把角色卡和聊天记录带走。

模型由你自己选择，API Key 由你自己提供。默认的「演示模式」不需要联网，也不需要 Key，适合先体验界面。

### 主题皮肤

设置中可随时切换六套完整主题。每套主题都包含独立壁纸、应用图标、角色头像和界面色板：

- 玫瑰霜：玫瑰粉与珍珠白，柔软但不甜腻
- 月墨：午夜蓝与月白，适合夜里慢慢说话
- 青瓷雾：青瓷绿与瓷白，安静克制
- 海盐玻璃：海盐青与沙白，明亮轻快
- 琥珀暮：琥珀与烟褐，温暖而怀旧
- 紫雾晨：丁香紫与晨粉，轻盈有梦气

### 应用图标

六套主题共有 72 枚独立绘制的 SVG 应用图标，覆盖聊天、角色、动态、电话、相册、日记、纪念日、钱包、音乐、论坛、记忆和设置。图标不是从壁纸裁切、取色或叠滤镜得到的，而是按主题分别设计外形、材质和符号语言：

- 玫瑰霜：玫瑰珐琅圆角方牌，奶油色实心符号与花瓣点缀
- 月墨：深色切角方牌，细线月光符号与星点
- 青瓷雾：高挑瓷牌轮廓，瓷白实心符号与竹叶、山茶印记
- 海盐玻璃：不规则海玻璃卵石，玻璃实心符号与气泡、贝壳纹理
- 琥珀暮：八边形琥珀切面，暖色实心符号与光带、胶片尘点
- 紫雾晨：淡紫圆形玻璃，深紫线描符号与蝴蝶、紫藤点缀

图标以 SVG 源码生成并内嵌进单文件 HTML，放大不糊，也不依赖外部图片文件。生成脚本位于 `scripts/generate-theme-icons.py`。

### 生活事件引擎（v0.5 新增）

角色不只在你发消息时存在。重新打开手机时，余温机会按你离开的时长结算一小批“你不在的时候”发生的事：

- 角色动态：角色自己发一条朋友圈，偶尔有其他角色点赞或评论
- 角色日记：角色写下一段当天的心情和片段
- 未接来电：电话记录里留下一条未接来电
- 主动消息：角色先给你发一条消息，聊天列表出现未读角标

这些事件全部由本地模板生成，不需要 API，也不会在你离开期间无限堆积。结算结果会出现在锁屏“你不在的时候”卡片、桌面 widget 和回顾弹层里，点开就能回到对应应用。

生活节奏可以选：

| 节奏 | 大约间隔 | 每天上限 | 每次回来最多 |
| --- | --- | --- | --- |
| 安静 | 6 小时 | 2 件 | 1 件 |
| 正常 | 2 小时 | 5 件 | 2 件 |
| 热闹 | 45 分钟 | 8 件 | 3 件 |

设置里可以关闭生活引擎，也可以点“模拟一次三小时的离开”立即预览效果。生活状态会随完整备份一起导出，清空全部数据时一并重置。

### 时间感与勿扰（v0.5.1 新增）

聊天提示词里会注入一层很轻的“时间感”：当前日期、星期、时段、上一条消息隔了多久、今天已经聊了多少条。模型不需要报时，也不会提到系统时间或定时器，只会把“隔了半天才回”“这是今天第一句话”当成背景，自然接上。

每条离线事件都会带一条发生原因，例如“3 小时没说话 · 突然想起你”。回顾卡上能直接看到这条原因，事件不再像随机掉落的模板。

设置里新增勿扰时段（默认 `23:00–08:00`，可关闭）。勿扰期间角色照常写日记、发动态，但不发消息、不打电话、不弹通知。生活还在继续，只是不打扰你。

### 长期记忆分层（v0.6.0 新增）

记忆不再只有“重要度”一个维度。每条记忆会带一个层级和一组标签：

- 事实：姓名、住处、工作、稳定信息
- 偏好：喜欢 / 不喜欢、口味、习惯
- 共同经历：一起做过的事、最近发生的事
- 关系：约定、承诺、边界、关系变化
- 阶段总结：一段时间的整体状态

召回时会综合置顶、重要度、层级、标签、时间衰减和最近使用次数排序。寒暄和短句不会把整本记忆库塞进提示词；只有检测到“记得 / 上次 / 以前 / 喜欢 / 约定”等信号时才召回。被用过的记忆会更新最近使用时间，重复事实会合并标签和来源，而不是无限追加。

记忆库会显示每条记忆的层级、来源和标签。手动添加记忆时默认“自动判断”，也可以手动指定层级。

## 快速开始

### 方式一：直接双击

打开项目中的 `余温机.html`。源码构建后的文件默认位于项目根目录：

```text
余温机.html
```

发布包中直接打开同目录的 `余温机.html` 即可。

这是最简单的使用方式。`file://` 模式下数据保存在 localStorage，适合体验和轻量使用。

### 方式二：本地静态服务器

照片、音乐较多时，建议用本地服务器打开，以启用 IndexedDB：

```powershell
npm run serve
```

然后访问：

```text
http://127.0.0.1:8080/余温机.html
```

也可以使用 Python：

```powershell
python -m http.server 8080
```

## 接入模型

进入「设置 → 模型接口」，选择服务商，填写接口地址、API Key 和模型名。

| 服务商 | 接口地址 | 示例模型 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| Claude / Anthropic | `https://api.anthropic.com` 或 `https://api.anthropic.com/v1` | `claude-3-5-sonnet-latest` |
| Gemini | `https://generativelanguage.googleapis.com` | `gemini-2.0-flash` |
| SillyTavern / 本地兼容 | `http://localhost:8000/v1` | 按后端要求填写 |
| 自定义 OpenAI 兼容 | 你的兼容接口 `/v1` 地址 | 你的模型名 |

注意事项：

- API Key 只保存在当前浏览器本地，不会上传到作者服务器。
- 导出完整备份时，所有 API Key 会被清空。
- 浏览器直连需要接口允许 CORS。被拦截时，可以通过 SillyTavern、One API、LiteLLM 或自建反向代理转发。
- Claude 直连需要接口允许 `anthropic-dangerous-direct-browser-access`。
- Gemini 的 Key 会拼在请求地址中，请只在可信设备上使用。
- 模型调用产生的费用由用户自行承担。

## 数据与备份

- `http://` / `https://`：优先使用 IndexedDB。
- `file://`：使用 localStorage，单文件双击即可运行。
- 备份入口：`设置 → 数据 → 导出完整备份`。
- 导入备份会覆盖当前数据，导入前会二次确认。
- 角色卡、聊天记录、完整备份都是普通 JSON，可以自行检查和迁移。
- 浏览器清理站点数据会删除本地内容，建议定期导出备份。

## 开发与构建

```powershell
cd work/ember-phone-v0.5
npm run check
npm test
npm run build
```

构建结果默认写入项目根目录：

```text
余温机.html
```

需要把构建结果输出到指定目录时：

```powershell
node build.mjs --out ../../outputs
```

项目没有运行时依赖，不需要 `npm install`。主题壁纸、头像和 SVG 图标在构建时以内嵌 data URI 写入单文件 HTML，因此最终产物仍可离线双击打开。

### 接口自测

项目带一个本地模型接口模拟器，可验证 OpenAI 兼容、Claude 和 Gemini 的请求格式，以及真实模型路径下的自动记忆提炼：

```powershell
node tests/mock-provider.mjs
```

然后在设置中把接口地址指向 `http://127.0.0.1:8787` 或 `http://127.0.0.1:8787/v1`，API Key 随便填，模型名随便填。

## 设计原则

- **本地优先**：角色、聊天、照片、设置都在浏览器里。
- **可迁移**：角色卡、聊天和备份都是普通 JSON。
- **用户自备模型**：不绑定单一厂商，不收 API 转售费用。
- **单文件可运行**：不依赖后端，双击就能体验。
- **不复制受限成品**：界面、代码和数据结构均为本项目原创实现，不包含付费小手机的私有代码或素材。
